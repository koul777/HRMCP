# Legacy Ontology Notice

NCS-SQF ontology design is deprecated for the active MCP.

The current ontology is NCS task-centered:

- `performance_criteria` are task nodes.
- `ksa_atomic_items` are atomic KSA candidates.
- `ontology_concepts` are representative KSA concepts.
- `task_ksa_concept_relations` stores KSA relations needed for task execution.
- `task_similarity_links` stores upskilling/reskilling task transitions.
- `ncs_training_course_concept_links` connects training courses to KSA concepts.

Recommendations must return NCS units, elements, performance criteria, KSA concepts, training courses, and evidence.

# 2017 NCS 온톨로지 논문과 현재 구현 비교

검토 대상: 진영근·이원구(2017), 「NCS “응용SW엔지니어링” 직무의 지식 관리 및 검색추론 지원을 위한 온톨로지 설계 연구」, 한국융합학회논문지 8(9), 17–23. DOI: 10.15207/JKCS.2017.8.9.017.
사용자가 제공한 PDF 7쪽 전부와 22쪽 그림 5·6을 확인했다. 이 문서는 설계 비교 자료이며 원천 훈련 데이터나 승인 기록이 아니다.

## 판단

논문은 NCS의 관계 구조화 필요성을 직접 뒷받침하는 선행연구다. 현재 프로그램과 완전히 동일한 온톨로지 모델이나 구현은 아니다. 프로젝트가 논문을 기반으로 개발되었다는 개발 이력도 확인되지 않았으므로 '논문을 그대로 구현했다'고 표현하지 않는다.

| 항목 | 논문 | 현재 프로젝트 |
|---|---|---|
| 도메인 구조 | NCS 분류·능력단위·능력단위요소·수행준거·KSA | 동일 계열 원천 계층을 별도 테이블과 링크로 구성 |
| 적용 범위 | 응용SW엔지니어링 한 직무, 23 능력단위·65 요소·213 수행준거·196 지식·186 기술·151 태도 | 전체 NCS를 대상으로 설계·구축하며 훈련·경력·자격·직업기초능력 연계로 확장 |
| 표현 | Protégé, OWL; primitive/defined class, 필요·충분조건 | SQLite 대표 개념·별칭·원문/원자 KSA 링크·관계 테이블 |
| 검색/추론 | OWL-DL 쿼리로 특정 지식을 요구하는 능력단위요소 검색 | SQL 관계 조회, 규칙 기반 후보 관계, 공유 KSA 기반 유사도와 교육 추천 |
| 관계 | 요소→수행준거·지식·기술·태도의 object property | 위 원천 연결과 더불어 knowledge_enables_skill, attitude_supports_skill 등 자체 후보 관계 |
| 실증 | 한 직무 온톨로지 구현 및 추론 검색 예시 | 추천 정확도·정의 품질·갱신 안정성은 프로젝트에서 별도 검증 필요 |

## 페이지별 근거

- 17쪽 초록: 단순 DB의 NCS 체계를 온톨로지화할 필요성과 한 직무의 구현 목적.
- 18쪽 서론: 분류체계 변경 전후 관리·용어 혼재·일관성 및 전체 NCS로의 확장 필요성.
- 19–20쪽: 클래스·관계 설계, primitive/defined class 구분과 필요·충분조건.
- 21쪽 표 2: hasAbilityUnitElement, hasPerformanceCriteria, hasKnowledge, hasTechnic, hasAttitude 등.
- 22쪽 그림 5·6: 지식·기술·태도 연결 구조 및 네트워크 개념 지식을 요구하는 능력단위요소 검색.
- 22쪽 결론: 전체 NCS 확장, 직무별 표준화, 자연어 질의 처리는 후속 연구 과제.

## 프로젝트에서 주의할 차이

`src/ncs_mcp/db.py`의 `build_task_ksa_concept_relations`는 같은 수행준거·요소에 연결된 원자 KSA를 유형별로 조합해 `candidate` 관계를 만든다. 고정 confidence 0.62/0.58/0.54는 구현 규칙의 값이며, 논문이 검증한 확률이나 해당 지식·기술의 인과관계 실증값이 아니다.

`build_task_similarity_links`의 공통 KSA 기반 과업 유사도 계산도 논문의 OWL-DL 클래스 추론과 다르다. JSON-LD 내보내기 기능의 존재만으로 OWL 공리나 reasoner가 구현되었다고 볼 수 없다.

논문도 유사·중복 KSA 문장의 의미 통일을 위한 검증 필요성을 지적한다. 이는 프로젝트의 KSA 정규화·개념 통합 검토 필요성과 맞닿지만, 현재 boilerplate 정의나 미검토 후보의 의미 정확성을 보증하지 않는다.

권장 표현: **“NCS를 능력단위·수행준거·KSA의 관계로 구조화한다는 선행연구의 방향과 부합하며, 교육 추천과 운영 갱신을 위해 별도의 관계 모델 및 구현을 확장한 시스템이다.”**

피해야 할 표현: “논문과 완전히 동일하다”, “논문으로 추천 정확도가 입증됐다”, “논문의 OWL-DL 추론을 그대로 구현했다”, “이 논문이 MCP·Vercel 자동 갱신의 신뢰성을 검증했다.”
